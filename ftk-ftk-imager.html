Apa itu FTK / FTK Imager?

FTK / FTK Imager adalah suite forensik (FTK) + utilitas imaging gratis (FTK Imager) dari Exterro yang digunakan dalam proses investigasi digital forensik.

FTK dipakai untuk pengelolaan bukti digital skala besar dengan indexing & preview, sementara FTK Imager menjadi tool standar untuk membuat dan memverifikasi salinan forensik disk, image, dan memory.

Dalam praktik sehari-hari, tool ini dipakai oleh laboratorium forensik, penegak hukum, tim incident response korporasi, konsultan digital forensik, serta penyidik internal untuk mempercepat pekerjaan akuisisi dan analisa bukti tanpa mengorbankan integritas data. Penggunaan yang tepat selalu diawali dengan penilaian kondisi barang bukti, pemilihan metode yang paling kecil dampaknya (minimally invasive), dan dokumentasi hasil yang rapi.

Kami menyediakan FTK / FTK Imager beserta lisensi/subscription, pendampingan instalasi, pelatihan hands-on berbasis studi kasus, hingga dukungan lanjutan saat tool digunakan pada perkara nyata.

Fitur Utama FTK / FTK Imager

  • FTK Imager: create image, mount image read-only, capture memory, verify hash
  • Preview file & artefak (email, registry, gambar) sebelum analisa penuh
  • Hash set / known file filtering untuk memangkas data tidak relevan
  • Indexing teks penuh untuk pencarian cepat pada dataset besar
  • Ekspor bukti terpilih + laporan pemeriksaan
  • Utilitas gratis FTK Imager sering dipakai untuk triase awal

Alur Kerja FTK / FTK Imager

Urutan pemakaian yang umum diterapkan di laboratorium agar hasil tetap forensically sound dan dapat dipertanggungjawabkan.

1

Gunakan FTK Imager + write blocker untuk membuat image (raw/E01) dan capture memory bila perlu.

2

Verifikasi hash sumber vs image, dokumentasikan chain of custody.

3

Import image ke FTK, buat index, dan muat hash set known-file.

4

Lakukan pencarian keyword/artefak, tandai item signifikan (bookmark).

5

Ekspor bukti terpilih + laporan untuk penyidikan/persidangan.

Prinsip yang tidak boleh dilewatkan: selalu kerjakan pada salinan (image), bukan barang bukti asli, gunakan write blocker saat mengakses media, verifikasi hash sebelum dan sesudah proses, serta catat setiap tindakan dalam formulir chain of custody.

Studi Kasus Hands-on

Contoh Penggunaan FTK / FTK Imager

Dua skenario berikut menggambarkan cara tool ini dipakai pada investigasi nyata — mulai dari persiapan barang bukti sampai hasil yang dilaporkan ke penyidik.

1

Triase cepat dengan FTK Imager

Skenario: Tim perlu memutuskan disk mana yang layak dianalisa lebih lanjut.

Langkah Pengerjaan

  1. 1.Boot laptop forensik, koneksikan disk via write blocker.
  2. 2.Buat image raw + capture RAM bila sistem masih hidup.
  3. 3.Verifikasi MD5/SHA1, catat di form bukti.
  4. 4.Preview artefak penting (email, browser) untuk penilaian awal.

Contoh Output / Laporan (ilustrasi)

Image: DISK-A.dd (500.107.862.016 bytes) MD5: 55aa...10cd | SHA1: 7b31...9f22 | Verify: OK Memory: MEM-A.raw (16GB) captured Preview: Outlook PST 2.1GB, Chrome history 92 hari Decision: full examination warranted (priority HIGH)
2

Pencarian dokumen kontrak hilang

Skenario: Sengketa bisnis: kontrak disebut pernah dibuat tapi tidak ditemukan di server.

Langkah Pengerjaan

  1. 1.Import image server ke FTK, bangun index teks penuh.
  2. 2.Muat hash set OS/application untuk mengurangi noise.
  3. 3.Cari kombinasi keyword nama kontrak & nomor referensi.
  4. 4.Telaah file yang terhapus namun berhasil di-carving.

Contoh Output / Laporan (ilustrasi)

Indexed items: 4,9 juta (filtered known files: 3,1 juta) Keyword hits: 'Perjanjian Kerja Sama No. 114' -> 38 docs Carved: KONTRAK_114_rev2.docx (deleted, cluster 0x...) recovered Report: FTK-exhibit-03.pdf + file exhibit folder
