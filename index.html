Computer Forensics

Disk imaging • Data carving • Timeline analysis

Hands-on akuisisi dan analisis bukti dari hard disk/SSD: write-blocking, imaging, carving file terhapus, dan rekonstruksi aktivitas pengguna.

Mobile Forensics

Android & iOS extraction • App & chat recovery

Ekstraksi dan analisis bukti dari perangkat mobile: logical/physical extraction, pemulihan pesan WhatsApp/Telegram, log panggilan, dan geolocation.

Cellebrite UFED / Physical Analyzer MSAB XRY Oxygen Forensic Detective ADB / Fastboot

Network & Memory Forensics

PCAP analysis • Incident reconstruction

Analisis paket jaringan dan memori untuk rekonstruksi insiden siber: deteksi intrusi, exfiltration tracing, dan analisis malware di RAM.

Wireshark Zeek / Bro NetworkMiner Volatility 3

Malware Analysis

Static & dynamic analysis • Reverse engineering dasar

Pembongkaran sampel malware secara aman di sandbox: identifikasi indikator (IoC), perilaku, persistence mechanism, dan network callback.

Ghidra x64dbg PE-bear / Detect It Easy CAPE / Any Run
